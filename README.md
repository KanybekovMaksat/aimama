# Листовка «AI Мама» для родителей студентов Codify

Двусторонняя A5 (148 × 210 мм). Заголовок «AI Мама». Лицевая сторона (без подзаголовка): что такое ИИ (лид и три факта с пояснениями), формула запроса, три готовых запроса «Попробуйте сегодня вечером» (правила безопасности убраны по выбору пользователя 2026-10-14), оффер «бесплатная AI-диагностика 60 минут» с QR в WhatsApp. Оборот: словарик из 5 слов, таблица «сайт — что на нём делать» (8 сервисов из программы AI Start), блок AI Start одним абзацем плюс строка «начать с диагностики», без программы по месяцам, цены и дат (убраны пользователем 2026-10-14), контакты с иконками: WhatsApp из Simple Icons 13 (CC0), Instagram из Lucide 0.544 (ISC) и три филиала. Метки «AI мама» нет, вместо неё пиксельные сердечки. Оформление типографическое: 4 размера шрифта (30/14/9.2/7 pt), одна толщина линий, один акцентный синий, без рамок и полос; единственная плашка — бесплатная диагностика. Подсказка «наберите слово в слово» убрана. Так попросил пользователь («слишком много фигур»).

## Откуда данные

- Контакты, адреса филиалов, формулировка диагностики: сайт codifylab.com (снято 2026-10-13).
- Параметры и программа AI Start: `docs/courses/ai-start.html`.
- Цвета и шрифт: `codify-app-web/design/tokens.css` (oklch переведён в hex), Nunito Variable из приложения.
- Логотип: `idcodify/public/codify-logo.svg`. AiCo убран по просьбе пользователя, вместо него пиксельные сердечки (функция `heart` в build.mjs).

## Что подтвердить перед тиражом

1. Дата старта групп «2 ноября» и цены 12 000 / 40 000 сом.
2. Возраст AI Start 11–17 (в CRM встречается 9–13).

## Печать

A5, цветная, двусторонняя, переворот по короткому краю, без полей. В типографии попросить вылеты 3 мм: фон белый, цветные блоки не доходят до края, поэтому обрезка безопасна.
